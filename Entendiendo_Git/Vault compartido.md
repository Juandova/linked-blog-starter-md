Para crear un vault compartido primeramente se debe generar un vault en local conectado a Github. Para ello se sigue [este tutorial](https://forum.obsidian.md/t/the-easiest-way-to-setup-obsidian-git-to-backup-notes/51429)

Tras establecer la conexión será necesario dar permisos de edición al usuario con el que se quiere compartir el vault. 

![[Pasted image 20260612190414.png]]

Se utiliza la función `Add people` y se busca al usuario Github con el que se quiere compartir el repositorio.

El resto de pasos es igual pero cambiando el token a la hora de añadir el link. 

>[!caution] El link debe quedar de esta forma!
>```
>https://<Usuario_Compartido>@github.com/<Usuario_original>/<Repositorio_original>.git
>```

Y se sigue con el resto del tutorial de la misma forma,  crear carpeta, y reiniciar.
