> [!summary] Etiquetas estándar en los comentarios que algunos IDE detectan automáticamente.


| Etiqueta     | Descripción                                             |
| ------------ | ------------------------------------------------------- |
| `TODO`       | Algo pendiente de implementar o mejorar.                |
| `FIXME`      | Hay un problema conocido que **debería corregirse**.    |
| `NOTE`       | Información importante para quien lea el código.        |
| `HACK`       | Una solución temporal o poco elegante                   |
| `BUG`        | Describe un fallo conocido.                             |
| `OPTIMIZE`   | Algo funciona pero podría ser más eficiente.            |
| `PERF`       | Algo funciona pero podría ser más eficiente.            |
| `WARNING`    | Llama la atención sobre una limitación importante.      |
| `DEPRECATED` | Código que debería desaparecer.                         |
| `REVIEW`     | Algo que funciona pero se quieres revisar más adelante. |
| `QUESTION`   | cuando todavía se está diseñando algo                   |
